# A4 Image Cutter 1.0.0 / A4 이미지 분할 편집기 1.0.0

Release date / 배포일: 2026-09-22

## English

This is the first public release of A4 Image Cutter.

Highlights:

- Interactive A4 grid and split-page editing
- Independent locking and editing of image fragments
- Configurable margins in millimetres
- Multiple page selection and output exclusion
- Page image export and enhanced print preview
- Offline processing with no third-party runtime dependencies

Install by extracting `A4ImageCutter-v1.0.0-win.zip` and running `A4ImageCutter.exe`.

The executable is not code-signed, so Windows SmartScreen may ask for confirmation.

## 한국어

A4 이미지 분할 편집기의 첫 공개 배포 버전입니다.

주요 기능:

- 대화형 A4 격자 및 분할 페이지 편집
- 이미지 조각별 고정 및 독립 편집
- mm 단위 인쇄 여백 설정
- 여러 페이지 선택 및 출력 제외
- 페이지 이미지 저장 및 확장 인쇄 미리보기
- 외부 런타임 라이브러리와 네트워크 연결이 필요 없는 로컬 처리

`A4ImageCutter-v1.0.0-win.zip`의 압축을 풀고 `A4ImageCutter.exe`를 실행하면 됩니다.

실행 파일에 코드 서명이 없으므로 Windows SmartScreen 확인 창이 표시될 수 있습니다.
