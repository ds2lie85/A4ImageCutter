# Security Policy / 보안 정책

## Supported Version / 지원 버전

**English:** Security fixes are currently provided for version 1.0.x.  
**한국어:** 현재 1.0.x 버전에 보안 수정이 제공됩니다.

## Reporting a Vulnerability / 취약점 보고

**English:** Please avoid posting sensitive vulnerability details in a public issue. Contact the repository owner through the GitHub profile at <https://github.com/ds2lie85/>. Include reproduction steps, affected versions, and the expected impact.  
**한국어:** 민감한 취약점 상세 내용은 공개 이슈에 게시하지 말아 주세요. <https://github.com/ds2lie85/>의 GitHub 프로필을 통해 저장소 소유자에게 연락하고, 재현 방법·영향받는 버전·예상 영향을 포함해 주세요.
